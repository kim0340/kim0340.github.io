카카오톡 문의

서비스 소개

같은 동남아라고 다 똑같지 않습니다.
어디서 망고따고 바나나따고 하던 어중이 떠중이 데려다 일시키지 않습니다.
던파, 메이플, 리니지클래식으로 이어지는 10년차 게임으로 밥먹고 사는 엄선된 직원만 근무 합니다.
모든 계정은 1:1 전담 직원이 근무 합니다.
일용직 직원 채용 하지 않습니다.

시간 비용

  • 비용은 10시간
  • 육성은 12시간~
  • 클래스별 육성비는 10시간으로 계산
  • 육성 시간은 10시간 + @ 서비스 타임제공
  • PC방 비용은 별도 계산

육성 회비

  • 기사 : 1시간 1,200원
  • 요정 : 1시간 2,200원
  • 법사 : 1시간 3,200원
  • 군주 : 1시간 2,200원

※ 피시방 비용은 별도 입니다.(1시간 1,000원)
육성비는 월간 구독의 개념 선불입니다.
비용은 10시간, 육성 시간은 12시간
(피시방 비용은 별도 계산입니다.)
클래스별 육성비는 10시간으로 계산
육성 시간은 10시간 + @ 서비스 타임제공
피시방 비용은 11일,21일,31일 마다 후불 입니다.
피시방 비용은 리니지를 실행 시킨 시간만 체크 됩니다.
월간 구독 개념으로 + @ 서비스 타임 제공의 이유는 사람이 하는 일인지라 일정상의 미미한 차질에대한 이해를 해주십사하기 위함입니다.
서버 점검, 임시 점검, 간혹 있는 직원의 휴무 등에 대한 세심한 배려를 부탁드립니다.
그렇다고 하여 근무 기준에서 크게 벗어나진 않습니다.
문제가 될 만큼의 차질이 있는 경우 차액 환불 해드립니다.

작업 안내

PC방에서 로그인 합니다.
PC는 24시간 ON.
오직 본주님 케릭만 로그인 하는 전용 좌석 입니다.
일반 지피방 아닙니다.
(퍼플과 동일한 기반의 원격 사용)
주 사냥터는 PC방 본던 5~7층, 사던4층, 에바왕국 입니다.
최소 8,9검 5,6셋 이상 부터 가능합니다.
1시간 평균 1만 아데나 정도의 소모품 비용은(HP) 본주님 부담입니다.
각 클래스별 용기, 악마의피, 엘븐와퍼 비용은 본주님 부담입니다.
(요정 클래스 윈드워크 사용시 와퍼는 본주님 희망에 따릅니다.)
클래식샵 상품 포션을 사용하는 경우 별도의 아데나 필요하지 않습니다.
획득하는 아데나 및 아이템은 전부 사무실 귀속입니다.
PC방 깃털 및 이벤트 보상 등은 전부 본주님 귀속입니다.
케릭터 사망시 즉시 복구 처리 합니다.
복구비용은 사무실 부담입니다.

부가 서비스

본주님 희망에 따라 근무 마감시, ATS ON 가능합니다.
PC방 접속 상태에서 NC 스트리밍 서비스 사용 가능.
지피방과 같은 개념으로 본주님이 개인적으로 사용 가능합니다.
일반 지피방과 같은 지피방 접속 지연 발생 없습니다.
직원근무시간+ATS사용시간+본주님사용시간을 합산하여 PC방비는 계산됩니다.
